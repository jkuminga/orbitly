# iPhone 빠른 실행 방법 조사

목표는 다른 화면을 사용 중에도 Orbitly에 할 일을 빠르게 저장하는 것입니다. 아래의 `빠른 할 일 입력` 단축어는 단축어 앱에서 제목을 입력 또는 받아쓴 뒤, 그 값을 `quick-add` 웹 경로에 전달합니다. PWA는 이 요청을 받아 로그인된 개인 계정의 `tasks`에 저장합니다.

## 권장 순서

1. **홈 화면 웹앱(PWA)**: Safari의 공유 메뉴에서 `홈 화면에 추가`를 선택합니다. 전체 할 일/루틴을 관리하는 기본 진입점이며, 웹페이지가 Safari 탭이 아닌 독립 앱처럼 열립니다.
2. **Back Tap + 빠른 할 일 입력 단축어**: 설정 > 손쉬운 사용 > 터치 > 뒷면 탭에서 삼중 탭에 단축어를 지정합니다. 제목을 받아쓰거나 입력한 뒤 `quick-add` 웹 경로를 열어 자동 저장합니다.
3. **동작 버튼 + 빠른 할 일 입력 단축어**: iPhone 15 Pro 이후의 동작 버튼 탑재 모델에서 설정 > 동작 버튼 > 단축어로 지정합니다. 한 번 길게 누르는 방식이라 오작동 가능성이 Back Tap보다 낮습니다.

## 지원 여부와 제약

| 방식 | iPhone 15~17 | 웹페이지 실행 | 비고 |
| --- | --- | --- | --- |
| 홈 화면에 추가 | 지원 | 가능 | PWA 메타데이터·아이콘을 추가한 뒤 사용 |
| Back Tap | 지원 | 가능 | 이중/삼중 탭에 단축어 지정 |
| 동작 버튼 | iPhone 15 Pro 이후 | 가능 | 일반 iPhone 15/15 Plus에는 없음 |
| Siri | 지원 | 가능 | “Siri야, 루틴 열어”처럼 단축어 이름을 말함 |
| 제어 센터 단축어 | 지원 | 가능 | 화면을 쓸어내린 뒤 한 번 탭 |
| 전원(측면) 버튼 세 번 클릭 | 웹 실행 불가 | 불가 | 손쉬운 사용 기능만 실행하도록 설계됨 |
| 볼륨 버튼 조합 | 웹 실행 불가 | 불가 | 볼륨 조절/시스템 기능용이며 임의 단축어 할당 설정이 없음 |

## 구현 결론

첫 버전은 **PWA 홈 화면 아이콘 + Back Tap**을 채택합니다. Orbitly는 전체 관리에 사용하고, Back Tap은 제목을 즉시 입력·저장하는 `빠른 할 일 입력` 단축어에 연결합니다. 단축어가 Supabase에 직접 접근하지 않고, 로그인된 PWA의 `quick-add` 경로가 저장하므로 개인 계정의 인증과 RLS 정책이 유지됩니다. 전원 버튼 세 번 클릭과 볼륨 키 조합은 사용자 지정 웹 실행 경로로 지원되지 않으므로 포함하지 않습니다.
