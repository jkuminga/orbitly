# Orbitly 빠른 할 일 입력 단축어

`빠른 할 일 입력`은 iPhone의 Back Tap으로 어느 화면에서나 할 일을 저장하는 단축어입니다. 단축어는 Supabase에 직접 접근하지 않고, Orbitly의 `quick-add` 웹 경로에 제목만 전달합니다.

## 단축어 만들기

1. 단축어 앱에서 `+`를 누르고 이름을 `빠른 할 일 입력`으로 지정합니다.
2. `입력 요청` 액션을 추가하고 프롬프트를 `할 일을 입력하세요`로 설정합니다. 키보드의 마이크로 받아쓰기도 가능합니다.
3. `URL` 액션을 추가하고 아래 형식으로 입력합니다. `제공된 입력`은 2단계의 결과 변수입니다.

   ```
   https://YOUR_ORBITLY_DOMAIN/quick-add?title=[제공된 입력]
   ```

4. `URL 열기` 액션을 마지막에 추가합니다.

## Back Tap 연결

설정 > 손쉬운 사용 > 터치 > 뒷면 탭 > `삼중 탭`에서 `빠른 할 일 입력`을 선택합니다. 이중 탭보다 삼중 탭이 오작동이 적어 권장됩니다.

## 사용 전 확인

- Safari에서 Orbitly에 한 번 로그인해야 합니다. 단축어가 여는 `quick-add`는 Safari의 로그인 세션을 이용해 `tasks`에 저장합니다.
- `YOUR_ORBITLY_DOMAIN`은 웹앱을 올린 뒤 실제 주소로 바꿉니다.
- `tasks`는 한 번 완료하면 끝나는 할 일 테이블입니다. 저장된 항목은 Orbitly의 오늘 목록에 바로 나타납니다.
